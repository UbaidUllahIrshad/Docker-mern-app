# MERN Docker App
Full stack MERN application containerized with Docker.

## Tech Stack
- Frontend: React
- Backend: Node.js + Express  
- Database: MongoDB
- Containerization: Docker + Docker Compose

## Run with Docker
git clone https://github.com/UbaidUllahIrshad/Docker-mern-app
cd Docker-mern-app
docker compose up -d

## Services
- Frontend: http://localhost:3000
- Backend: http://localhost:5000
- MongoDB Express: http://localhost:8081
